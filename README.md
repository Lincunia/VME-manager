# VME Manager

Hello, this is the repository of a manager that checks your computer state. It
was done for learning purposes, but if someone finds it interesting, I'd be
very thankful since there are a lot of features to be checked

<details>
    <summary>Running the Java GUI</summary>

Place yourself [here](./src/java_gui/) and simply run you run `mvn package` so
that you can get a .jar file in the target/ directory and you can test the
program.
